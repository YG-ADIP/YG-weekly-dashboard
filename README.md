# YG 주간 대시보드 (팀 공개용, 파일럿)

`YG_Ella_work`(엘라 개인 작업 기록 저장소, 비공개)와는 완전히 별개의 저장소입니다. **이 저장소엔 실제
회사 데이터가 전혀 커밋되지 않습니다** — 화면 코드(HTML/CSS/JS)와 Google Apps Script 코드 사본만
들어있고, 실제 KPI 숫자는 항상 Google Apps Script를 통해 실시간으로만 가져옵니다. 그래서 이 저장소를
Public으로 둬도 안전합니다.

## 구조

```
docs/
  index.html    ← 운영 화면 (팀원들이 실제로 보는 링크)
  preview.html  ← 미리보기 화면 (엘라가 새 기능을 먼저 확인)
apps-script/
  Code.gs       ← 구글 Apps Script 백엔드 코드 사본(실제 배포는 엘라 구글 계정 안에서 함)
```

GitHub Pages가 `docs/` 폴더를 그대로 웹사이트로 서빙합니다. 이 저장소에 `git push`만 하면
수십 초~1분 안에 자동으로 반영됩니다(별도 "배포" 버튼 없음).

## 접근 방식

- **팀원**: 구글 계정도, 클로드 계정도 필요 없음. 사이트 링크로 들어가서 **공통 비밀번호**만 입력.
- **비밀번호 검증**: 브라우저(클라이언트) 쪽이 아니라 Google Apps Script(서버) 쪽에서 함 —
  개발자도구로 우회 불가능.
- **데이터 접근**: Apps Script가 엘라 구글 계정 권한으로 대신 읽어옴 — 팀원 각자 구글드라이브
  접근 권한을 받을 필요 없음.

## Apps Script 백엔드 배포 방법 (엘라가 1회 직접 진행)

1. [script.google.com](https://script.google.com) → 새 프로젝트
2. `apps-script/Code.gs`의 내용을 그대로 복사해서 붙여넣기
3. 좌측 ⚙(프로젝트 설정) → 스크립트 속성 → 속성 추가
   - 키: `DASHBOARD_PASSWORD`
   - 값: 팀에서 쓸 공통 비밀번호(원하는 걸로)
4. 우측 상단 **배포 → 새 배포**
   - 유형 선택(⚙) → **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   - 배포
5. 배포 완료 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해서
   대시보드 담당자(클로드)에게 전달 → `docs/index.html`·`docs/preview.html`의
   `APPS_SCRIPT_URL` 상수에 반영됨

**코드를 수정하고 다시 배포할 때**: 배포 → 배포 관리 → 기존 배포 수정(연필 아이콘) →
새 버전으로 배포 (이러면 URL이 안 바뀜, "새 배포"를 다시 누르면 URL이 바뀌어서 앞단 코드도 같이
고쳐야 함 — 웬만하면 "배포 관리 → 수정"만 쓸 것).

## 현재 범위 (1차 파일럿)

- KPI 카드(2026 KPI 목표/실적/달성률/잔여 KPI + 주별 추이)만 구현됨.
- 나머지(팀 AGENDA/트렌드/사업캘린더/월별트래킹/팀일정캘린더)는 이 파일럿 검증 후 같은 패턴으로 추가 예정.
- 원본(더 풍부한 기능, 클로드 아티팩트 버전, 비밀번호 없음)은 엘라 개인용으로 별도 유지 —
  `YG_Ella_work/DB대시보드/주간회의_대시보드.html`.
