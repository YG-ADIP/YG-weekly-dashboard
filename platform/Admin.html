0. 협업 DB

팀원이 화면에서 직접 입력·저장하는 데이터 저장소(구글 시트 1개)입니다. 만들면 대시보드의 KPI·팀 AGENDA·트렌드 리포트·계약 알림·인사이트가 기존 시트 대신 협업 DB에서 계산됩니다.

확인 중…

· 기존 시트 데이터 가져오기: 팀 AGENDA·트렌드 리포트의 지난 주차 전체, 실적현황 시트의 주차별 KPI 기록·목표를 협업 DB로 옮깁니다. 여러 번 눌러도 중복되지 않습니다.
· 사업 원장(BIS)은 대시보드 [사업 원장] 탭에서 BIS 엑셀을 그대로 업로드하세요.

1. 기본 정보

대시보드 제목과 기준 연도입니다. 섹션 이름의 {year}는 기준 연도로 바뀝니다(예: {year} KPI 현황 → 2027 KPI 현황).

2. 데이터 연결

구글 시트·폴더·캘린더의 주소(URL)를 그대로 붙여 넣으면 ID는 자동으로 추출됩니다. 바꾼 뒤에는 아래 [연결 테스트]로 먼저 확인하세요.

3. KPI 예비 목표

평소에는 최신 주차 시트의 목표를 그대로 씁니다. 시트에 목표가 비어 있을 때만 이 값(억원)을 씁니다.

4. 사업 캘린더

계약 알림 시점과, 팀 구글 캘린더에서 '사업 일정'으로 자동 분류할 기준입니다.

사업 일정 표시 기호

5. 팀 일정 캘린더 · "차주엔~" 배지

팀 일정 캘린더 상단 배지에 자동으로 보여줄 일정 기준입니다.

6. 섹션 구성

섹션 순서(▲▼), 표시 여부, 이름을 바꿉니다. 번호(01, 02…)는 표시되는 섹션 순서대로 자동으로 매겨집니다. 사업 캘린더·트렌드 리포트가 바로 이웃하면 좌우 2칸으로 배치됩니다.

번호순서섹션 이름표시

7. 연결 테스트 결과

입력한 값(저장 전 포함)으로 각 시트·캘린더를 실제로 열어 보고, 필요한 표가 있는지 확인합니다.

아직 실행하지 않았습니다.

8. 보안 — 비밀번호 변경

바꿀 항목만 입력하세요(4자 이상). 대시보드 비밀번호를 바꾸면 팀원에게 새 비밀번호를 공유해야 합니다.

9. 변경 이력

저장할 때마다 그 시점의 설정 전체가 기록됩니다(최근 20건). [되돌리기]를 누르면 그 시점 설정으로 즉시 복원됩니다.

10. 코드(드롭다운) 관리

사업 원장 입력 칸의 선택 목록입니다. 비워 두면 기본값을 씁니다. 진행 단계는 한 줄에 이름|가중치(%)|설명 — 가중치 100 = 진행 확정(KPI 실적 인정), 1~99 = 진행 중(가중 예상), 0 = 불발·보류.
